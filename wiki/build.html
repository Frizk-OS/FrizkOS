Compilation Guide

Step-by-step instructions for compiling FrizkOS from source code.

We rely on a strictly isolated Docker build environment. Modern Linux host systems utilize toolchains that will fatally break the compilation of legacy C/C++ kernel and framework components. Using Docker ensures a clean, reproducible build phase.<

/p>

1. Prepare the Build Environment

Clone the build environment repository and construct the Docker image. This image contains the required outdated toolchains, specifically GCC 4.7 and legacy glibc libraries.

git clone https://github.com/frizk-os/android_build_env.git
cd android_build_env
docker build -t frizkos-env .

2. Sync the Source Tree

Initialize the repository and sync the source code. Allocate adequate disk space and ensure a stable connection.

docker run -it --rm -v $(pwd)/frizkos_src:/src frizkos-env /bin/bash
cd /src
repo init -u https://github.com/frizk-os/android.git -b kitkat
repo sync -j$(nproc --all)

3. Configure CCache

Compiling the OS from scratch takes considerable time. Enabling compiler caching is mandatory for subsequent builds, as it dramatically reduces compilation time for native C and C++ binaries.

export USE_CCACHE=1
prebuilts/misc/linux-x86/ccache/ccache -M 50G

4. Start the Compilation

Set up the build environment. If you are switching between targets (e.g., from i9300 to golden), you must execute make clobber to purge incompatible object files before compiling.

source build/envsetup.sh

# Wipe previous target binaries
make clobber 

# Build for your target
brunch i9300
# OR
brunch golden
Success: Upon successful compilation, the flashable .zip package will be located at out/target/product/[CODENAME]/. Use TWRP or a fastboot wrapper to flash the image.
